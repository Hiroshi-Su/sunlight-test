# Windows での確認のお願い（room モード）

（2026-10-27）

room モードを Windows の PC で流したときの確認をお願いするための引き継ぎ。Mac では起きないことを、Windows の PC で確かめてもらう。計算の中身は [`docs/room.md`](room.md)（8.6 節・16 節の 18）。

## これまでの経緯

| 日付 | 起きたこと | 今の状態 |
|---|---|---|
| 2026-10-27 | Windows の Chrome で、表面が「うねり」のガラス（天井・奥）に、黒い点が縦に並んだひび割れのような線がちらついた | **直った**（3b0fadf）。Windows で一度確認済み |
| 2026-10-27 | URL に `&gpu=webgl` を付けると、画が黒くなって固まった | まだ調べていない |

黒い縦線の分かったこと：

- 線は視点を回すと一緒に動いた（画面の決まった列ではなく、部屋の中や外の決まった向きの所）
- `&glassSurface=flat`（ガラスを平らに）で消えた。`&pool=0`（水盤を消す）では消えなかった。雲はもともとオフ
- 原因：Windows の GPU（WebGPU の中は Direct3D）で、うねりのあるガラスの所の計算が、まれに壊れた値（NaN）になる。Mac（Metal）では起きない
- 直し方：1 画素の中の 4 点のうち、壊れた値の点を捨てて、残りの点の平均で埋めるようにした（WebGPU 版・WebGL2 版の両方）。どの式で壊れた値になるかまでは突き止めていない

## 準備

1. 最新版を取る：`git pull`（`main` の c632328 以降）
2. はじめてなら `npm install`
3. `npm run dev` で開発サーバーを起こし、Chrome で `http://localhost:5173/?mode=room` を開く
4. 部屋の設定（`config/room.json`）は git に入っていないので、その PC で保存してある設定がそのまま使われる。ガラスの表面を必ず「うねり」にして確かめたいときは、URL に `&glassSurface=swell` を付ける

パネルのいちばん下の文字に、確認に使う値が出る：

- `描画 WebGPU  倍率 1` … 描き方（WebGPU か WebGL2）と、画面の拡大率
- `計算 873×575` … 実際に計算している画の大きさ
- `FPS 60.0（1 フレーム 16.7 ms）` … 重さ

## 確認 1：黒い縦線が出ないこと（お願いしたいのはこれ）

一度は消えたことを確かめたが、時間や見え方を変えても出ないかを見る。

| # | やること | 見ること |
|---|---|---|
| 1-1 | いつもの設定で、10 分以上流す | 黒い点・線がちらつかないか |
| 1-2 | マウスで視点を左右・上下に回す。ホイールで寄る・引く | どの向きでも出ないか |
| 1-3 | URL に `&glassSurface=swell` を付ける（全部のガラスをうねりに） | 出ないか |
| 1-4 | URL に `&glassSurface=wave` を付ける（波打ち） | 出ないか |
| 1-5 | URL に `&glassSurface=reeded` を付ける（リブ） | 出ないか |
| 1-6 | 画面の「時刻」の欄のスライダーで、昼・夕方・夜に変える（URL なら `&t=2026-11-24T12:00` のように付ける） | どの時間でも出ないか |
| 1-7 | ブラウザの窓の幅を少しずつ変える（計算の大きさが変わる） | 出ないか |

出た場合は、次を送ってほしい：

- 写真か動画（線が分かるもの）
- そのときの URL 全部
- パネルのいちばん下の文字（全部）
- 線がどの面（天井・奥のガラス・右左のガラス・床）に出たか

## 確認 2：WebGL2 版が固まる件（必要なときだけ）

ふだんは WebGPU で描くので、WebGPU が使えない PC で流す予定がなければ、やらなくてよい。

| # | やること | 見ること |
|---|---|---|
| 2-1 | URL に `&gpu=webgl` を付けて開き、2〜3 分待つ | 画が出てくるか、黒いまま固まるか |
| 2-2 | 固まったら F12 で開発者ツールを開き、Console の赤い文字（エラー）を写す | `CONTEXT_LOST`・`shader`・`timeout` などの言葉があるか |
| 2-3 | アドレス欄に `chrome://gpu` と入れて開き、「Graphics Feature Status」と「GL_RENDERER」の行を写す | GPU の名前と、WebGL の描き方（ANGLE の Direct3D11 など） |

見込み：Windows の WebGL は描画の計算を Direct3D 用に訳し直すので、この部屋の大きな計算では、その訳し直しに時間がかかりすぎて止まった可能性が高い（まだ確かめていない）。

## 確認 3：重さ（ついでに）

確認 1 のいつもの設定で、パネルの `FPS` と `1 フレーム … ms` を写してほしい。GPU の名前（`chrome://gpu` の GL_RENDERER の行）も一緒に。Mac（Apple M4）では、四角い部屋で 1 フレーム約 6〜9ms。
